alembic : 데이터베이스 변경 이력 관리
현재프로젝트에 alembic 적용

uv run alembic init alembic

uv run alembic revision --autogenerate -m "add views"
uv run alembic revision --autogenerate -m "create board_views"

명령어
초기화 : alembic init 폴더명 => 지정한폴더 + *.init_db
마이그레이션 파일 생성 : alembic revision --autogenerate -m 메세지
최신 db 상태로 업그레이드 : uv run alembic upgrade head
이전 버전으로 롤잭 : alembic downgrade -1
